# Тудушник школьника: макет в словах

Рабочий документ. Первый фокус — 9 и 10 класс: развилка с профилем и контур подготовки. Числа в макетах (баллы, дни) — иллюстрации, не данные. Реальные числа берутся только из [10-данные-доклад-вшэ.md](10-данные-доклад-вшэ.md). Правила шага и стоп-лист — в [12-квесты-спека.md](12-квесты-спека.md).

## Место в продукте

Второй экран. Главный остаётся за выбором и лентой: бюрократию на входную дверь не выносим, это прямое замечание клиента ([08-замечания-клиента.md](08-замечания-клиента.md)).

Тудушник открывается из строки состояния на главном экране:

```
Я делаю: 3 · Ждёт тебя: 1 · Ближайший срок: 14 дней   →
```

Нажатие на строку ведёт сюда. Дел, которые делаем мы, на этом экране нет. Они видны только как «Я делаю: 3» и раскрываются по нажатию на эту цифру (источник, дата, основание).

## Пять правил

1. В списке только дела школьника.
2. Срок объясняется последствием: что закроется и можно ли вернуть.
3. Задачу закрывает внешний результат, а не галочка в нашем приложении.
4. У задачи три состояния: «ты», «мы», «ждём события».
5. Просрочки нет. Есть «закрылось»: что осталось и когда следующий шанс.

Серий, очков и уровней нет. Единственный показатель, который может ухудшиться, — разрыв до целевого балла: без замера больше месяца он помечается устаревшим.

## Анатомия задачи

Видна на карточке сразу:

- **Что сделать.** Повелительное наклонение, словами школьника: «Назови, куда точно не пойдёшь».
- **Что закроется.** Одна строка: «К весне профиль выберется без твоего отсева».
- **Когда и можно ли вернуть.** Метка «не вернуть» или «можно поменять до …».
- **Одна кнопка действия.** По форме результата: «Назвать», «Приложить балл», «Проверить на Госуслугах».
- **Кнопка «Не так».** Отклонить задачу или оспорить её основание. Отклонённое сохраняется с причиной.

Скрыто за раскрытием (источник, дата данных, допущение), чтобы карточка читалась за секунду:

- **От нас.** Что мы делаем внутри этой задачи: карта профилей, разложение разрыва.
- **Как проверим.** Какой факт закроет задачу.
- **Почему это задача.** Основание и источник, как в ДНК: у каждой рекомендации есть перечень оснований.

## Экран «Сейчас», 9 класс, зима

Не больше трёх задач. Остальное ниже, свёрнуто.

```
┌──────────────────────────────────────────────────────────────┐
│  Сегодня                       Я делаю: 3 · Ждёт тебя: 1     │
├──────────────────────────────────────────────────────────────┤
│  СНАЧАЛА ЭТО                                                 │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ Назови, куда точно не пойдёшь                          │  │
│  │ Весной профиль выберется без твоего отсева             │  │
│  │ Не вернуть: после выбора профиля предметы фиксируют    │  │
│  │ перечень направлений на два года                       │  │
│  │                                                        │  │
│  │ [ Назвать ]                          [ Не так ]  ▾     │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                              │
│  ДАЛЬШЕ                                                      │
│   ○ Выбери предметы ОГЭ              весна · не вернуть      │
│   ◔ Запись на муниципальный этап     ждём списков школы      │
│                                                              │
│  ЗАКРЫЛОСЬ, НО МОЖНО ВЕРНУТЬСЯ                               │
│   ✕ Школьный этап ВсОШ — следующий через год                 │
│                                                              │
│  ┌───────────┬───────────┬───────────┐                       │
│  │  Сейчас   │  До срока │  Сделано  │                       │
│  └───────────┴───────────┴───────────┘                       │
└──────────────────────────────────────────────────────────────┘
```

Значки состояния:

- ○ ждёт тебя
- ◔ ждём события (не от тебя и не от нас)
- ● закрыто внешним результатом
- ✕ закрылось без тебя, с указанием следующего шанса

Значок «мы делаем» на этом экране не показывается: такие дела в цифре «Я делаю: 3».

## Раскрытая карточка

```
┌────────────────────────────────────────────────────────┐

│                                                        │
│ Что получится: список направлений, которые ты          │
│ исключаешь, и причина по каждому твоими словами.       │
│ Список можно менять в любой момент.                    │
│                                                        │
│ Исключено сейчас:                                      │
│  · Медицина — «не выношу вид крови»                    │
│  · Право — «не хочу работать с бумагами»               │
│  [ + добавить ]                                        │
│                                                        │
│ От нас: карта «профиль → предметы → направления».      │
│ Что каждый профиль открывает и закрывает, числами.     │
│ Какой выбрать — не говорим.                            │
│                                                        │
│ Как проверим: в списке есть направления, у каждого     │
│ причина. Пустой список или список без причин —         │
│ задача не выполнена.                                   │
│                                                        │
│ Откуда это: «ранний выбор измеримо выгоден».           │
│ Источник: [ доклад ВШЭ ] · данные на [ дата ]          │
└────────────────────────────────────────────────────────┘
```

Если он исключил всё и ничего не оставил, задача заканчивается списком исключений. Дописывать «выбери хоть что-нибудь» нельзя ([12-квесты-спека.md](12-квесты-спека.md), открытый вопрос 1).

## Экран «Сейчас», 10 класс, контур подготовки

Контур живёт здесь же, но с другим ритмом: задачи еженедельные.

```
┌──────────────────────────────────────────────────────────────┐
│  Сегодня                       Я делаю: 2 · Ждёт тебя: 2     │
├──────────────────────────────────────────────────────────────┤
│  СНАЧАЛА ЭТО                                                 │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ Сдай замер и пересчитай разрыв                         │  │
│  │ Математика · разрыв до твоей цели: 18 баллов           │  │
│  │ Последний замер был 5 недель назад: разрыв устарел     │  │
│  │                                                        │  │
│  │ [ Приложить балл ]                    [ Не так ]  ▾    │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                              │
│  ДАЛЬШЕ                                                      │
│   ○ Выбери объём занятий на неделю     твой выбор            │
│   ◔ Результат пробника по русскому     ждём школу            │
│                                                              │
│  РАЗРЫВ                                                      │
│   Математика  ██████░░░░  цель 85 · устарел                  │
│   Русский     ████████░░  цель 90 · 2 недели назад           │
│                                                              │
│  ┌───────────┬───────────┬───────────┐                       │
│  │  Сейчас   │  До срока │  Сделано  │                       │
│  └───────────┴───────────┴───────────┘                       │
└──────────────────────────────────────────────────────────────┘
```

Блок «Разрыв» связывает тудушник с экраном «Разрыв». Предмет измерения назван и внешнего происхождения (балл пробника или тренажёра). Полоска показывает разрыв до цели, которую поставил он. Если замера нет больше месяца, статус «устарел», полоска не растёт.

Приложить балл можно из пробника или тренажёра, в том числе ФИПИ. «Я готов» вписать нельзя. Балл хуже предыдущего принимается как корректный результат и не наказывается.

## Вкладка «До срока»

Пять жёстких отсечек на линии времени, между ними контур подготовки. Для каждой видно, что к ней должно быть сделано его рукой, и это ссылки на задачи.

```
 ВсОШ ──── Профиль и ОГЭ ──── Заявление на ЕГЭ ──── Подача и приоритеты ──── Согласие
 сентябрь   весна 9 класса      1 февраля, 11 кл.     окно кампании          срок согласия
  ●             ◔ ты здесь           ·                     ·                      ·

 Между ними:  контур подготовки — повторяется до даты экзамена
```

Правила вкладки:

- Прошедшие отсечки не краснеют. У каждой написано, что осталось: «следующий школьный этап через год».
- Даты, которые плавают из года в год, показываем именем события («срок согласия этого года»), без выдуманного числа.
- Не показываем чужие сроки, которых нет в его маршруте: вошедший в 10 классе не видит долг за 8–9.

## Вкладка «Сделано»

Выполненное не исчезает, а становится портфолио: грамоты, баллы, регистрации, подтверждающие документы, исключённые направления с причинами.

```
 2026
   ● Исключил направления           список из 4, с причинами
   ● Регистрация на школьный этап   подтверждение школы
   ● Пробник по математике          74 · скан бланка
```

Что это даёт: через два года документы лежат в одном месте и не надо их искать. Список исключённого с причинами питает раздел «я о тебе» и виден родителю только по решению школьника.

## Вид родителя

Тот же экран, тот же тон, но фильтр по типу задачи.

- **Видно:** сроки, деньги, документы, регистрации, замеры и разрыв (спор «сколько заниматься» снимается числом).
- **Скрыто, пока школьник не открыл:** «Назови, куда точно не пойдёшь», отклонённые варианты, причины, сомнения.

Скрытая задача у родителя не пропадает целиком. Он видит факт: «Одна задача про выбор направлений. Содержание у школьника» (открытый вопрос в [08-замечания-клиента.md](08-замечания-клиента.md), пункт 3: объявлять ли факт скрытых данных. До решения клиента показываем эту строку, а не молчим).

Что родитель делает сам: он видит задачи, которые касаются его (документы, деньги), и может закрыть их своим результатом. Задачу, где автор школьник («Назови», «Расставь приоритеты», «Подай согласие»), закрыть за него нельзя.

## Пустые состояния

Пустой экран — нормальная часть дизайна.

- **Нет срочного:** «Сегодня дел нет. Ближайшее решение — через 14 месяцев. Времени достаточно». Для 8 класса это главный экран, он снимает тревогу вместо того, чтобы её создавать.
- **Ждём события:** одна строка с датой и временем: «Списки обновятся завтра в 18:00. Мы напишем».
- **Всё закрылось:** без поздравлений и конфетти. Статус и ссылка на портфолио.

## Чего в тудушнике нет

- Серий дней, очков, уровней, значков за заход в приложение.
- Просроченных задач красным цветом.
- Задач вида «определись с профессией» и «добавь N вузов».
- Публичного сравнения с одноклассниками.
- Процентов без названного предмета измерения.
- Кнопки «Готово» без внешнего результата.
- Рекомендаций платного тренажёра без названной закрываемой темы.

## Откуда берутся задачи

На вход три факта. Класс, регион и самодекларация: «пока не знаю / примерно представляю / знаю направление / уже знаю несколько вузов». Класс и регион берём из профиля. Самодекларацию человек называет сам, мы её не диагностируем.

Класс включает цепочку и ничего больше. Девятый класс получает «Профиль и ОГЭ» и годовой шаг ВсОШ. Десятый получает контур подготовки и тот же годовой шаг. Вошедший в десятом не видит долг за девятый: стадии — состояния, а не воронка ([09-путь-пользователя.md](09-путь-пользователя.md)).

Регион подставляет даты. Календарь школьного и муниципального этапа, срок записи на ОГЭ в его школе. Где календарное число плавает, на карточке имя события, а не выдуманная дата.

Самодекларация снимает уже сделанное. «Знаю направление» не создаёт заново шаг «отсеки направления», если список исключений с причинами уже лежит в профиле. Пустой профиль получает цепочку целиком.

Дальше четыре правила сборки экрана.

1. В «Сейчас» не больше трёх карточек. Первая — ближайшая необратимая, автор которой школьник. Вторая — следующая его. Третья — ожидание внешнего события, если оно есть.
2. Шаг с автором «мы» в список не попадает. Он увеличивает «Я делаю» и раскрывается оттуда: источник, дата, основание.
3. Ожидание — не просрочка и не его долг. «Ждём списков школы» висит, пока не пришёл внешний факт.
4. Своя задача разрешена. Кнопка «Своя задача». Он называет, что сделать, какой результат это закроет и к какой дате. Метка «твоё». В цепочку отсечки такая задача не входит и счётчик «Ждёт тебя» не кормит, если у неё нет даты. Закрывает её названный им результат, а не галочка. Родителю она видна, только если школьник пометил её как срок, деньги или документ.

## Сценарий: 9 класс, развилка

Зима, до весны есть время, но развилка необратима. На полотне выбора он смотрит пробы. В тудушнике в этот момент три строки: отсев с причинами, предметы ОГЭ, ожидание муниципального этапа. Карта профилей — наша, она в «Я делаю», не карточка.

Ниже шаги в том порядке, в каком они становятся первой карточкой. Поля совпадают с каталогом [13-квесты-каталог.md](13-квесты-каталог.md). Если текст разойдётся, верен каталог.

### Назови, куда точно не пойдёшь

- отсечка*: Профиль и ОГЭ
- шаг воронки*: Область
- автор результата*: школьник
- форма результата*: артефакт
- на экране: «Сейчас», первая, состояние «ты»
- родителю: содержание скрыто. Видна строка «Одна задача про выбор направлений. Содержание у школьника»
- кнопка: Назвать
- результат: список исключённых направлений, у каждого причина его словами; список можно менять до выбора профиля. Если он отсёк всё, шаг на этом кончается
- цена пропуска: к весне 9 класса профиль выбирается без его отсева, предметы фиксируют перечень направлений на два года
- механизм влияния: ранний выбор даёт больше времени на подготовку и выше шансы поступить; решение за месяц до поступления или позже чаще связано с недовольством учёбой
- источник: «ранний выбор измеримо выгоден: больше времени на подготовку, выше шансы поступить и окончить вуз»; «те, кто принял решение за месяц до поступления или позже, значительно чаще недовольны учёбой»
- наша часть: карта «профиль → предметы → направления» в счётчике «Я делаю». Какой профиль выбрать — не говорим
- проверка: список с причиной и датой у каждого пункта, либо явная пометка «ничего не отсекаю». Пустой список без этой пометки и пункты без причин — шаг не выполнен

### Запиши по пробе: оставить или отсечь

- отсечка*: Профиль и ОГЭ
- шаг воронки*: Область
- автор результата*: школьник
- форма результата*: артефакт
- на экране: появляется первой, когда список исключений уже есть и остались направления без пробы. Состояние «ты»
- родителю: скрыто, та же строка про содержание
- кнопка: Записать
- результат: по двум или трём ещё не отсечённым направлениям после пробы записано «оставил» или «исключил» и причина
- цена пропуска: к весне 9 класса выбор идёт по описанию программы, а не по тому, как выглядит работа
- механизм влияния: направление — первичный фильтр; о специальности узнают от человека, который там работает
- источник: «Направление первично для 52%, вуз — для 22%»
- наша часть: даём пробу про содержание работы. Вывод о личности не делаем
- проверка: у каждой пробы решение и причина с датой. Просмотр без решения — шаг не выполнен. Если неотсечённых не осталось, шаг не требуется

### Назови предметы ОГЭ и зачем они

- отсечка*: Профиль и ОГЭ
- шаг воронки*: Предметы
- автор результата*: школьник
- форма результата*: артефакт
- на экране: «Дальше», пока не закрыт отсев; затем первая. Состояние «ты»
- родителю: виден срок и сам перечень предметов. Причины, зачем направление, — только если школьник открыл
- кнопка: Назвать предметы
- результат: перечень предметов ОГЭ его словами и у каждого — какие неотсечённые направления он держит открытыми
- цена пропуска: к весне 9 класса запись на ОГЭ без связи с направлениями, профиль и ЕГЭ потом не стыкуются с тем, что он не отбросил
- механизм влияния: основной канал поступления идёт через ЕГЭ, состав экзаменов задаётся раньше заявления в 11 классе
- источник: «ЕГЭ | 62,3%»; «90% усилий по подготовке нацелены на ЕГЭ»
- наша часть: сверяем перечень с картой и показываем, где связь рвётся. Предметы не назначаем
- проверка: каждый предмет привязан хотя бы к одному оставшемуся направлению и дате. Предмет без связи — шаг не выполнен

### Назови профиль и проверь, что не закрыл лишнее

- отсечка*: Профиль и ОГЭ
- шаг воронки*: Предметы
- автор результата*: школьник
- форма результата*: артефакт
- на экране: первая после предметов ОГЭ. Состояние «ты»
- родителю: виден названный профиль и числа открытых и закрытых направлений. Сомнения и отклонённое — скрыты
- кнопка: Назвать профиль
- результат: названный им профиль и сверка, какие неотсечённые направления остаются и какие предметы ЕГЭ из него следуют
- цена пропуска: к весне 9 класса школа фиксирует профиль, закрытое направление уже не открыть сменой предметов
- механизм влияния: девятый класс — ключевая точка выбора высшего образования, не старшая школа
- источник: «девятый класс, а не старшая школа, стал ключевой точкой выбора высшего образования»
- наша часть: числа открытых и закрытых направлений из карты. Профиль не рекомендуем
- проверка: профиль назван им, сверка с датой. Пустое имя или сверка без его списка — шаг не выполнен

### Оформи запись на предметы ОГЭ в школе

- отсечка*: Профиль и ОГЭ
- шаг воронки*: Предметы
- автор результата*: школьник
- форма результата*: регистрация
- на экране: первая, когда профиль назван. Состояние «ты», после подачи документов переходит в «ждём», пока нет подтверждения школы
- родителю: видна целиком. Это срок и документ
- кнопка: Приложить подтверждение
- результат: подтверждённая запись на состав ОГЭ, совпадающий с его перечнем и профилем
- цена пропуска: к срокам ОГЭ в конце 9 класса состав не совпадает с профилем, часть направлений закрыта до заявления на ЕГЭ
- механизм влияния: не измерено
- источник: нет
- наша часть: срок записи в его школе и сверка перечня со связкой «предметы — направления»
- проверка: справка школы, запись в журнале или подтверждение классного руководителя. Отметка у нас без документа не считается
- ревью: да

Рядом, не в этих пяти: муниципальный этап. Карточка в состоянии «ждём», пока школа не выложила списки. Это тот же шаг ВсОШ на следующий этап, не новая отсечка. Пропуск школьного этапа уже в «Закрылось»: следующий шанс через год, тона вины нет.

## Сценарий: 10 класс, контур

Один оборот, он повторяется до даты экзамена. Пять точек из спеки квестов. На экране школьника из них карточки только там, где автор он. Раскладку разрыва и пересчёт делаем мы.

### Назови целевой балл по каждому предмету

- отсечка*: контур подготовки
- шаг воронки*: Притязания
- автор результата*: школьник
- форма результата*: артефакт
- на экране: первая, пока балла нет. Состояние «ты». Родителю виден: это число, которым снимается спор «сколько заниматься»
- кнопка: Назвать балл
- результат: по каждому сдаваемому предмету записан его целевой балл; можно менять на следующем обороте
- цена пропуска: к дате ЕГЭ разрыв и план занятий считаются без его цели
- механизм влияния: подготовка к ЕГЭ — основной канал поступления, не олимпиада
- источник: «ЕГЭ | 62,3%»; «90% усилий по подготовке нацелены на ЕГЭ»
- наша часть: порог в баллах по неотсечённым направлениям. Целевой балл не подставляем
- проверка: у каждого предмета есть названный им балл и дата. Балл, который вписали не он, — шаг не выполнен

### Разложи разрыв по предметам и темам

- отсечка*: контур подготовки
- шаг воронки*: Предметы
- автор результата*: мы
- форма результата*: артефакт
- на экране: не карточка. Блок «Разрыв» и строка в «Я делаю»
- родителю: виден по умолчанию
- результат: по каждому предмету последний замер, его цель, разрыв и раскладка по темам. Нет замера — пометка «нет замера», разрыв не притворяется посчитанным
- цена пропуска: к дате ЕГЭ занятия идут без привязки к темам, где теряются баллы
- механизм влияния: разрыв переводит подготовку в план по предметам и темам
- источник: «62,3% зачислений по ЕГЭ»
- наша часть: считаем от его цели и последнего замера. Прогноз только с допущением и с возможностью оспорить
- проверка: блок заполнен, есть дата расчёта. Нет его цели — шаг не выполнен. Нет замера — шаг выполнен с пометкой «нет замера»

### Запиши объём на неделю

- отсечка*: контур подготовки
- шаг воронки*: Притязания
- автор результата*: школьник
- форма результата*: артефакт
- на экране: «Дальше», состояние «ты»
- родителю: виден объём в часах или задачах. Настрой и сомнения не показываем, их в шаге и нет
- кнопка: Записать объём
- результат: на неделю зафиксированы часы или число задач по предметам
- цена пропуска: к дате ЕГЭ нагрузка не сопоставима с разрывом
- механизм влияния: объём выбирает он; расходы семей на подготовку больше расходов на само обучение
- источник: «расходы семей на подготовку — 950 млрд рублей в 2022 году, вдвое больше расходов на само обучение»
- наша часть: какой объём закрывает текущий разрыв при названных допущениях. Число не назначаем
- проверка: по каждому предмету с ненулевым разрывом указаны часы или задачи и дата. «Настроился» или пустое поле — шаг не выполнен

### Сдай замер и обнови разрыв

- отсечка*: контур подготовки
- шаг воронки*: Предметы
- автор результата*: школьник
- форма результата*: замер
- на экране: первая, когда цель уже названа и замер устарел или его не было. Состояние «ты». Пересчёт — наша часть этой же карточки, отдельной задачи «пересчитай» нет
- родителю: виден балл и разрыв
- кнопка: Приложить балл
- результат: новый балл пробника или тренажёра, разрыв пересчитан. Месяц без замера — разрыв устарел и не стал лучше. Балл ниже предыдущего — корректный результат, экран не краснеет
- цена пропуска: к дате ЕГЭ план занятий опирается на старый разрыв
- механизм влияния: балл меняется от решённых задач и пробника, не от присутствия
- источник: «90% усилий по подготовке нацелены на ЕГЭ»
- наша часть: пересчитываем разрыв по темам и не улучшаем его до нового замера. Тренажёр называем только по проваленной теме и с основанием
- проверка: балл пришёл из пробника или тренажёра с датой. «Я готов» и кнопка у нас без внешнего балла — шаг не выполнен

Оборот после замера начинается снова с объёма, не с цели: цель меняют, только если он сам её переписал.

## Проверка шагов

Три условия допуска из [12-квесты-спека.md](12-квесты-спека.md): привязан к отсечке или контуру; результат проверяемый и автор его школьник (шаг «мы» допустим, только если без нашего артефакта его шаг нельзя начать, и таких в цепочке не больше двух); цена пропуска названа с датой или с именем события.

Четыре признака честного трекинга, где на экране виден прогресс: предмет измерения внешний; цель ставит он; счётчик растёт от работы; показатель умеет падать.

Запреты 1, 2, 9 и 10 из [00-манифест.md](00-манифест.md): не отвечаем «кем быть»; не выводим способности из баллов и поведения; не награждаем за действие, выгодное сервису; не делаем публичный счёт.

| Шаг | Допуск | Трекинг | Запреты | Итог |
|---|---|---|---|---|
| Назови, куда точно не пойдёшь | отсечка — весна 9 класса; артефакт его словами; цена названа | прогресс — не процент, а список с причинами. Список можно сузить и расширить, «достижение» потерять можно | «кем быть» не спрашиваем. Причина не становится ярлыком. Числа вузов нет | проходит |

Отдельно не прошли бы и в экран не попали: «Добавь 5 вузов», «Определись с профессией», «Заходи 7 дней», «Дойди до прогноза 90–93», отдельная карточка «Пересчитай разрыв» с кнопкой у нас.

## Три сценария для теста макета

Каждый должен пройти без вопросов к смыслу экрана.

1. **9 класс, зима.** Открывает приложение, видит три задачи. Нажимает «Назвать», исключает два направления с причинами. Задача закрывается, в «Сделано» появляется запись, родитель видит строку о том, что содержание у школьника.
2. **10 класс, пятая неделя без замера.** Видит устаревший разрыв, прикладывает балл пробника, разрыв пересчитывается. Балл хуже прошлого, и ничего не краснеет.
3. **Пропущенный школьный этап.** Через неделю после срока видит «закрылось», что осталось и когда следующий шанс. Тона вины нет.

## Открытые вопросы

1. Что показывать в июле и августе между стадиями, если все задачи закрыты.
2. Нужна ли явная отметка перехода 9 → 10 класс: «Профиль выбран, начинается контур подготовки». Решение влияет на то, показываем мы смену режима или делаем её незаметной.
3. Как показывать «ждём события», если дата неизвестна: «когда-то в июле» или честное «не знаем, скажем, как только узнаем».

Свои задачи решены в разделе «Откуда берутся задачи»: можно, с меткой «твоё», вне цепочек отсечек.
