# Аудит нарисованного через выбранную ДНК

Рабочий документ. Всё, что лежит в папке, разложено на «работает», «переделать» и «противоречит».

## Сценарий: Льготы и особые условия — эталон

Лучший документ в папке по соответствию ДНК. Его стоит использовать как шаблон для всего слоя 1.

| Элемент | Почему работает |
|---|---|
| «Пока мы собирали твой план поступления, я заметила несколько вещей, которые стоит проверить» | проактивность: сервис нашёл сам, человек не спрашивал |
| «В 3 из 5 выбранных вузов есть условия» с градацией Подходит / Нужно уточнить / Информация отличается / Проверить вручную | честная классификация, включая категорию «мы не знаем» |
| «Я бы не исключала №3, пока мы не проверим правила приёма» | прямое признание незнания вместо интонации уверенности |
| «Применимость нужно подтвердить в вузе», «проверим в правилах приёма» | названная граница ответственности |
| «Я помогу сориентироваться, но не подтверждаю юридическое право» | калька с ПризываНет, работает идеально |
| Блок «Было / Стало» с кнопками «Обновить мой план» и «Оставить как есть» | **обратимая рекомендация.** Тест на субъектность пройден образцово: возразить можно одним действием |
| «Не все олимпиады дают это преимущество» с объяснением про этапы | обучение правилам системы вместо голого вывода |

Единственное, что стоит добавить: дату актуальности данных у каждого утверждения о правилах вуза.

## Сценарий: Поиск олимпиады

**Работает.** Мини-проверка с кнопкой «Дать намёк» и результатом «что уже хорошо / что прокачать» — образцовый слой 2: измеримо, оспоримо следующей задачей. Подбор олимпиад с блоком «Почему тебе подходит: подходит по классу, можно пройти онлайн, есть задания прошлых лет, хороший вариант для первого участия» — лучший пример раскрытого основания во всей папке, причём каждый пункт фактический, ни одного оценочного. План занятий с кнопкой «Изменить дни» — человек владеет своим расписанием.

**Переделать.** Тон: «хочу затащить олимпиаду», «норм — уже хорошая база». Не проходит тест на единый голос — это не покажешь маме, сидящей рядом.

**Противоречит.** Ачивки «Охотник: 2 олимпиады», «7 дней подряд», счётчик «68% Олимпиады 42%» без указания, что это за проценты. Родителю не говорит ничего, подростку даёт ощущение прогресса, не связанное с поступлением.

## Вариант №2

**Работает, и это основной источник стандарта изложения.**

- «258 / 250 — твои ожидаемые / проходной в 2026» рядом с «на 8 баллов выше порога 2026 года. Это не гарантия поступления»
- «Подтверждено 168. Информатика — ожидаемые 90» — честность про качество собственных данных
- «Основание — совпадение предметов и пороги бюджета 2026 года, без баллов за достижения» — раскрытое основание с названным допущением
- «Порог может измениться» — признание неопределённости будущего
- Чек-лист документов «Готово 2 из 5», с различением обязательного и необязательного: «диплом нужен для достижения, не для всех заявлений»
- «Все 3 — черновики. Ничего не отправлено» — снятие ложной тревоги
- «Примерные сроки. Перед подачей уточни правила каждого вуза»
- «Только с твоего согласия. Файлы добавлены вручную, доступ к Госуслугам не подключён; без твоего согласия ничего не запрашиваем» — **готовая рамка согласия**, которая закрывает самую тревожную формулировку из vision
- «Достижения учитываются отдельно, по правилам вуза»

**Нейтрально, но недоиспользовано.** Видео «Один день студента ИТ · 01:24» и лента событий поданы как контент рядом с карточкой. При этом ровно это и есть механика слоя 3 — возможность попробовать до выбора. Стоит поднять из контента в инструмент.

**Переделать.** Главная слабость — пассивность: «Помочь с выбором? Спросите Сову». Сервис ждёт вопроса. Для ядра A инициатива на слое 1 обязательна.

**Под наблюдением.** В профиле «12 просмотров за месяц, 2 обращения от вузов». Полезно как факт, опасно как метрика самооценки.

## Вариант №3

**Работает.** Шаги «1/6 … 6/6» с кнопкой «Пропустить» на каждом — субъектность уважается процедурно. Экран «Вот что я уже знаю о тебе. Собрал из нашего диалога» с кнопкой «Редактировать информацию» — **это проходит тест на субъектность:** человек может сказать «нет, не так», и сервис станет точнее. Находка, которую надо сохранить и распространить на все выводы сервиса. «Есть шансы на медаль. Медаль даст +3 балла или 100 баллов к ЕГЭ в некоторых вузах с пилотными программами» — чистый слой 1, точно и полезно. «Что сильнее всего повлияет: математика — основной резерв роста» — слой 2, проверяемо.

**Противоречит.**

| Элемент | Проблема |
|---|---|
| «Посмотрел твой дневник → Ваши сильные стороны: Логика, Технические предметы, Творчество» | вывод о личности из оценок; оценка измеряет соответствие программе, не интерес |
| «У тебя сильная база для IT и технических направлений» | присвоение оценочной части вопроса; возразить нечему |
| «Шанс поступления 64%» | число без раскрытого основания и без допущения |
| «Прогноз результата 81 → 90+», «Прогноз после выполнения плана: 90–93 балла» | обещание результата, за который мы не отвечаем |

Переделка не требует выбрасывать механику: прогноз остаётся, но с источником, допущением и возможностью оспорить — ровно так, как это уже сделано в варианте №2 для порогов.

## Для вас — серия

| Макет | Вердикт |
|---|---|
| «Вот твой план. Ты сейчас тут. Тебе нужно сделать вот это сейчас / а завтра / а это следующий шаг» | **работает:** хорошая проактивная структура слоя 1, человек всегда знает, где он |
| «Добавь 5 ВУЗы в избранное и получи ачивку» | **противоречит прямо:** внутренняя метрика сервиса выдана за задачу пользователя. Добавление вузов ради награды искажает сам выбор |
| «УРА ТЫ ПОСТУПИЛ, ЗАБИРАЙ ФИНАЛЬНУЮ АЧИВКУ И ПОДЕЛИСЬ» | **противоречит:** поступление как ачивка обнуляет серьёзность события, ради которого всё делалось |
| «Ты очень крутой. Твой профиль смотрели уже 444 раза и 23 вуза» | **противоречит:** превращает поступление в соцсеть и создаёт тревогу у того, у кого просмотров три |
| Карта «Рядом. Вы 400 м» | **работает:** слой 1, прямо отвечает на запрос Леры про города и условия переезда |
| «Интересуюсь / Хочу сюда» | **работает:** лёгкая декларация намерения без обязательства |

## Vision: Выгрузка Подбор_Вуза

| Блок | Вердикт |
|---|---|
| Лента и сниппеты | **механика работает, название противоречит.** «Хакнуть внимание» описывает манипуляцию. Но Миша не может представить учебный день, а Соня видит, что похожие названия скрывают разное содержание — им нужен опыт, не рекомендация. Переформулировка: дать попробовать профессию на вкус до того, как выберешь |
| «hh Портфолио, чтобы не быть NPC» | **механика работает, рамка противоречит.** Вузы находят школьника — это снимает беспомощность. Но «не быть NPC» стыдит пользователя, а главное: обращение вуза становится новым каналом давления. Нужна оговорка, что интерес вуза не является нашей рекомендацией |
| «Фабрика агентов: Госуслуги уже все знают об абитуриенте» | **противоречит в формулировке.** «Всё знают» не равно «имеют право использовать». Рамка согласия обязательна, и она уже написана в варианте №2 |
| «Создание и обучение 10-ти ИИ агентов» | **нейтрально-вредно:** количество агентов как цель. Пользователю безразлично, сколько их |
| Единый дашборд поступления | **работает без оговорок:** ядро слоя 1 |
| Отзыв «не пришлось платить другим ресурсам по подбору» | **работает:** готовая формулировка экономической роли |
| «52% бросали из-за визуальной слаборазличимости контента», «численные показатели ≠ качественное взаимодействие» | **работает:** честная самодиагностика, редкость для документа такого жанра |

## Сова как маскот

Форма допустима, распределение по слоям обязательно: слой 2 — естественная среда (тренажёр, проверки, план), слой 1 требует точности вместо подмигивания, слой 3 — спокойствия без давления. Условие одно: регистр не меняется в зависимости от того, кто смотрит.

## Сводка по судьбе элементов

**Сохранить как есть:** весь сценарий льгот, систему оговорок и раскрытых оснований варианта №2, мини-проверки и блок «почему тебе подходит» из сценария олимпиад, экран «вот что я знаю о тебе» с редактированием, рамку согласия, карту, «интересуюсь / хочу сюда», структуру «ты сейчас тут».

**Переделать:** прогнозы и шансы — раскрыть основание; ленту — переформулировать из захвата внимания в пробу; портфолио — убрать стыд и добавить оговорку про обращения вузов; тон Совы — свести к единому регистру; видео — поднять из контента в инструмент выбора.

**Выбросить:** ачивки за действия, выгодные сервису; поступление как финальная ачивка; публичный счёт просмотров профиля; выводы о способностях из школьных оценок; счётчики процентов без указания предмета измерения.
